# richhabits/homebrew-tap

Homebrew tap for [SAM](https://github.com/richhabits/sam) — a free, private, local-first AI assistant.

```bash
brew install --cask richhabits/tap/sam
```

- **Apple Silicon:** current cask is **3.7.0** (`SAM-3.7.0-arm64.dmg`).
- **Intel:** 3.7.0 did not ship an Intel DMG. The cask installs the last Intel build, **3.5.0**. For anything newer, clone and run `./setup.sh`.

SAM is **source-available**, not MIT. See the [LICENSE](https://github.com/richhabits/sam/blob/main/LICENSE).
